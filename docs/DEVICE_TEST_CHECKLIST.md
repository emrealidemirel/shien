# Fiziksel cihaz kabul kontrolü

Her senaryoda cihaz/model, işletim sistemi, uygulama sürümü, sonuç ve varsa tekrar adımları kaydedilmeli. Bu tablo henüz gerçek cihazda tamamlanmadı.

| Senaryo | Android | iPhone |
|---|---|---|
| Yeni kurulum, misafir, bildirim izni kabul/ret | Bekliyor | Bekliyor |
| Kilitli ekran, uygulama kapalı, üç ses/sessiz | Bekliyor | Bekliyor |
| Odak/sessiz modu ve pil kısıtlamaları | Bekliyor | Bekliyor |
| Yeniden başlatma sonrası hatırlatma | Bekliyor | Bekliyor |
| Bildirimden tamamla/ertele, geçmişte tek kayıt | Bekliyor | Bekliyor |
| Widget aç/tamamla/ekle, hesap değişimi sonrası eski eylem | Bekliyor | Bekliyor |
| Google/e-posta kayıt, giriş, doğrulama, parola sıfırlama | Bekliyor | Bekliyor |
| Apple giriş, e-posta gizleme, iptal | Uygulanmaz | Bekliyor |
| İki cihaz: ekle, değiştir, tamamla, sil | Bekliyor | Bekliyor |
| Çevrimdışı değişiklik, yeniden açma, bağlantı geri gelmesi | Bekliyor | Bekliyor |
| Aynı kaydı iki cihazda değiştirme: son sunucu yazısı | Bekliyor | Bekliyor |
| Misafirden hesaba aktarım ve tekrar aktarım | Bekliyor | Bekliyor |
| Hesap silme, tekrar giriş, eski cihazın veri göndermesi | Bekliyor | Bekliyor |
| Saat dilimi, yaz saati, ay sonu, uzun süre açmama | Bekliyor | Bekliyor |
| TR/EN, koyu tema, büyük yazı ve ekran okuyucu | Bekliyor | Bekliyor |
| JSON dışa/içe aktarma, iptal, bozuk dosya | Bekliyor | Bekliyor |

Herhangi bir veri kaybı, başka hesaba veri taşınması veya tekrarlanabilir çökme yayın engelidir. Simülatör ve birim test sonuçları bu tabloda fiziksel cihaz sonucu olarak işaretlenmemeli.
